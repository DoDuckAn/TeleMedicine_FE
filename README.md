# KhamBenhTuXa Frontend

Next.js frontend for the telemedicine system.

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Default backend API:

```text
http://localhost:4000/api/v1
```

Planning context lives in [`FRONTEND_PLAN.md`](./FRONTEND_PLAN.md). Backend API context lives in [`../API.md`](../API.md).

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run typecheck
npm run format
```
